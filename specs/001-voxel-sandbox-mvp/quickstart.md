# Quickstart

## Prerrequisitos
Unity 2022.3 LTS, .NET 6

## Setup
1. Abrir proyecto en Unity Hub
2. Abrir escena Scenes/Main
3. Build > Build and Run

## Validación
- Ejecutar juego, crear mundo nuevo
- Verificar romper/colocar bloques
- Verificar persistencia al reiniciar

Esperado: mundo generado, bloques interactivos, inventario funcional.
