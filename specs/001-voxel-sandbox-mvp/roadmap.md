# Roadmap Voxel Sandbox Libre

## Fase 1 - MVP Core Desktop
Objetivo: Loop jugable singleplayer.
Entregables: generación chunks, romper/colocar, inventario, crafting básico, día/noche, guardado.
Gates: 60 fps con 100 chunks, tests TDD, assets propios.
Duración estimada: 4-6 meses equipo 6-8.

## Fase 1.5 - Input y Accesibilidad
Objetivo: Soporte completo de joystick y accesibilidad.
Entregables: Input System unificado teclado/ratón/gamepad, mapeo configurable, vibración, opciones de accesibilidad.
Gate: pruebas con 3 gamepads distintos.

## Fase 2 - Multijugador Base
Objetivo: Mundo compartido.
Entregables: servidor dedicado, sincronización chunks, anti-cheat básico, Realms-like gratuito.
Gate: 10 jugadores concurrentes estables.

## Fase 3 - Sistemas Avanzados de Jugabilidad
Objetivo: Paridad mecánica.
Entregables: sistema lógico tipo redstone, biomas avanzadas, estructuras, IA mobs mejorada.
Gate: benchmark de reproducción de mecánicas clave.

## Fase 4 - Ecosistema y Contenido
Objetivo: Sostenibilidad.
Entregables: Modding API, editor de skins, Marketplace propio gratuito, pases de temporada.
Gate: auditoría legal y seguridad.
