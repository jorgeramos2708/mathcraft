# Feature Specification: Multiplayer Base

**Feature Branch**: `[003-multiplayer-base]`

**Created**: 2025-10-15

## User Stories

### US1 - Conectar a servidor
Jugador puede unirse a servidor dedicado.

### US2 - Sincronizar mundo
Chunks y bloques se sincronizan entre clientes.

### US3 - Chat y presencia
Jugadores ven lista y pueden chatear.

## Requirements
- FR-001: System MUST permitir conexión cliente-servidor.
- FR-002: System MUST sincronizar chunks.
- FR-003: System MUST validar acciones de bloques.

## Success Criteria
- SC-001: 10 jugadores concurrentes estables.
